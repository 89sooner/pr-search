# 00_governance

## Purpose

Defines how every other document is read, written, prioritized, and updated, and records change requests and gate passes in `change_control.md`.

## For AI Agents

- Edit with care. Changes here alter the meaning of every downstream document.
- When adding a new document type, register its role, priority, and update rule here before writing the document.
- After governance edits, re-check `docs/README.md` priority and cascade sections.
- Scope/baseline changes start with a CR row in `change_control.md`; close the CR only after the cascade and validator pass are recorded.
