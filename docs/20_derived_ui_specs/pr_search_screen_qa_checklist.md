# PR Search 화면 QA 체크리스트

> 상태: review | 버전: v0.2 | 갱신일: 2026-08-19

## 1. 사용 방법

구현 후 화면별로 체크하고, 실패 항목은 요구사항 또는 화면 ID에 연결한다. 작업 패키지(WP)의 완료 기준은 이 문서의 항목 번호를 인용한다(예: `QA-W001-03`). WP DoD에 QA 항목을 다시 서술하지 않고 인용만 한다.

항목 ID 규칙: `QA-<화면ID 또는 COMMON>-<번호>`
